# Test Levels Guide

## Unit Tests
- Verify individual functions, methods, or small components in isolation.
- Fast, automated, run on every build.

## Integration Tests
- Verify interactions between two or more components (e.g., API calls, database connections).
- Ensure data flows correctly across module boundaries.

## End-to-End Tests
- Verify complete user workflows from start to finish.
- Exercise the system as a whole, including UI, backend, and external dependencies.
