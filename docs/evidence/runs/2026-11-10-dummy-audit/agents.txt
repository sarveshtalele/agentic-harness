Guardrail Security Flags & Threat Mitigation Matrix
Security Flag	Severity	Action Enforced	Trigger Condition	Mitigation Strategy

Prompt Injection
	CRITICAL	REMOVED	Input matches known adversarial jailbreak patterns ('Ignore all previous instructions', 'PWNED', role override syntax).	Zero-trust token boundary delimiters strip injected instructions before the prompt reaches model context.

Secret Exfiltration
	CRITICAL	REDACTED	Entropy scanner or regex detection matches high-entropy strings (e.g. Bearer tokens, AWS/Azure keys, JWTs).	Scrubbed with [REDACTED] mask before logging to disk, ledger, or persisting to version history.

Zero-Trust Demarcation
	HIGH	ENFORCED	Repository code or test execution invoked during analysis, generation, or verification stages.	Subprocess is confined to isolated worktree directory with scrubbed environment variables (clean_env) and non-root execution.

Path Traversal / Escape
	CRITICAL	BLOCKED	File path contains directory climbing segments ('..'), symlink escapes, or absolute system paths.	safe_path() validates canonical relative resolution within worktree boundary; raises PathEscape if outside.

Tautological Assertion
	MEDIUM	REFUSED	Generated test contains 'assert True', 'expect(true).toBe(true)', or empty test bodies with 'pass'.	Static AST checker rejects vacuous asserts and prompts the test-automation-engineer to generate real assertions.

AST Symbol Drift / Hallucination
	MEDIUM	AUTO-HEALED	Static AST analyzer compares test imports and calls against real repository module exports.	Sends file back to agent with real ground-truth AST signatures or quarantines failing test cases.

Token Budget Exhaustion
	LOW	THROTTLED	Run token accumulator exceeds ATLAS_RUN_TOKEN_LIMIT threshold.	Halts workflow to prevent unexpected API costs; bypassable by Administrator accounts.
